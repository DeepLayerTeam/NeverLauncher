# Поиск неисправностей

## API не стартует / `/ready` возвращает ошибку

Проверьте DSN PostgreSQL, миграции, учётные данные Redis, права доступа к хранилищу, секреты подписи и обязательные списки разрешённых выпусков. Серверный API в промышленной среде намеренно блокирует небезопасную конфигурацию. Не отключайте проверки готовности вместо устранения первопричины.

## Desktop не запускает Minecraft

Зафиксируйте ОС/архитектуру, основную версию Java, версию Minecraft, загрузчик, выбранный профиль/канал, хеш манифеста и обезличенную диагностику. Проверьте доступность исходных проектов и соответствие статусов [матрице](../clients/compatibility.md). Не считайте ряд `required: false` сертифицированным.

## ServerBridge не регистрируется

Проверьте совместимость JAR-файлов сервера и расширения, ключи удостоверения, одноразовую регистрацию, статус узла и сетевой доступ. Если отказ связан с повторной регистрацией, проверьте процесс безопасной ротации удостоверения: прямая перезапись уже зарегистрированного ключа недопустимо.

## Расширение не стартует

Проверьте подпись и реестр, явно выданные разрешения, ограничения хоста, секреты и события аудита. Нельзя игнорировать состояние карантина или отключения. См. [Extensions](../extensions/overview.md).

## Диагностика без секретов

Используйте группы `nl diagnostics collect|redact|validate|bundle` и `nl operations diagnostics`. Перед загрузкой логов удалите пароли, токены доступа и обновления, приватные ключи, DSN и персональные данные. Общие проблемы с CI: [ci.md](ci.md).
