# Extensions

Extensions — система расширения возможностей Backend, Desktop и CLI. В проекте предусмотрены реестр, подписанные пакеты, управление версиями, установка и обновление, жизненный цикл, протокол взаимодействия с хостом, разрешения и обработка событий.

## Где начинать

- `extensions/` — файлы целевых сценариев/сертификации.
- `sdk/` — доступные SDK и типы.
- `examples/extensions/` — примеры расширений серверной части и CLI.
- `cli/cmd/launcher/main.go` — команды `nl extension ...` и альтернативная команда `nl plugin ...`.
- `services/api/internal/extension*`, `services/api/internal/httpapi/extension*` — серверная реализация.

## Жизненный цикл

Подготовка метаданных → упаковка → подпись и проверка → импорт и установка → выдача разрешений → включение → вызовы хоста → телеметрия и аудит → обновление, откат, отключение или удаление. Доверенный администратор должен иметь возможность отозвать разрешение и оперативно отключить расширение.

Полный список CLI включает `extension init|dev|test|build|pack|sign|verify|registry|updates|trust|quarantine|emergency|recovery|installed|install|enable|disable|update|rollback|uninstall|permissions|secrets`; конкретные опции проверяйте командой `nl` и исходниками.

## Ограничения

**Не запускайте недоверенные расширения без оценки границ изоляции.** Уровень изоляции зависит от ОС; разрешения и подписи не заменяют изоляцию процессов и проверку содержимого. Подробности в [security-and-lifecycle.md](security-and-lifecycle.md).
