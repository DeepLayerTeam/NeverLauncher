# Launcher 0.25.8 — интерфейс текстур Desktop

## Что входит в поставку

Раздел **Desktop → Скины и плащи** — полноценный интерфейс React, встроенный в существующую навигацию приложения и жизненный цикл сеанса Launcher (не iframe, заглушка или имитация Backend). Он использует уже развёрнутые API текстур Backend версий 0.25.1–0.25.7 и разделяет две идентичности:

- **Локальный Launcher:** использует аутентифицированный сеанс Launcher и канонический UUID Minecraft, принадлежащий серверу. Доступны библиотека сохранённых изображений (12 на страницу), выбранная текстура, ревизия, предварительный просмотр галереи, выбор существующего PNG, загрузка и импорт, сброс и удаление, изменение модели и видимости, история и сообщения об ошибках разрешений.
- **Официальный Minecraft:** использует только учётную запись Microsoft, явно привязанную в разделе **Вход**, и действующий шлюз Minecraft Services. Поддерживаются загрузка официальных скинов, выбор только принадлежащих пользователю официальных плащей, сброс скинов/плащей и получение актуального официального профиля. Ни локальный UUID, ни идентификаторы локальных файлов текстур не передаются официальным сервисам. Официальный сеанс ограничен областью действия сеанса Launcher и очищается при выходе.

Предпросмотр отображает аватар Minecraft с моделью classic/slim и настоящей раскладкой UV атласа скинов Java, включая дополнительные слои 64x64. В режиме **3D** текстурированные кубы с трёхмерными преобразованиями позволяют вращать модель перетаскиванием указателя; плащ расположен за аватаром, доступны передняя, задняя и боковые поверхности. Режим **2D** показывает плоскую фронтальную проекцию и отдельный двухмерный просмотр плаща. Для пиксельной графики применяется `image-rendering: pixelated`. Дополнительные библиотеки времени выполнения не нужны. Скины повышенного разрешения сохраняют исходные пропорции UV. Этот исключительно визуальный клиентский рендеринг не заменяет проверку и загрузку полного PNG на сервере.

Закрытые PNG галереи владельца загружаются с аутентифицированным bearer-токеном; временные объектные URL `blob:` отзываются при размонтировании галереи/предпросмотра или смене выбора. На страницу загружается 12 изображений. Frontend никогда не включает токен Launcher в URL изображения. Официальные скины показываются только с `textures.minecraft.net` по путям `/texture/<hash>` с каноническим HTTPS, явно разрешённым в CSP Tauri. Произвольный внешний URL изображения, предоставленный пользователем, не используется как источник предпросмотра.

## Поведение

1. Откройте Desktop и выполните вход в Launcher через раздел **Вход**.
2. Откройте **Скины и плащи**. Явно выберите локальную или официальную идентичность; выбор локальной идентичности не переключает идентичность запуска в фоновом режиме.
3. Выберите **Скины** или **Плащи**. Загрузите PNG (до 4 МиБ), укажите classic/slim (только для скина) или выберите сохранённый материал; сервер проверяет формат и геометрию Minecraft. Импорт по внешнему HTTPS выполняется существующим серверным загрузчиком с защитой от SSRF.
4. Отслеживайте ход загрузки и ошибки. Локальные запросы передают `expectedRevision` для CAS и обновляют выбор и библиотеку после изменений; HTTP 409 обновляет актуальное состояние без небезопасного автоматического повтора.
5. Вращайте 3D-модель указателем или переключитесь на 2D; просматривайте библиотеку и историю ревизий. **Сбросить** удаляет назначение, сохраняя PNG. **Удалить** удаляет запись библиотеки (предварительно сбрасывая её, если она активна) после подтверждения.
6. Для официальной идентичности подключите Microsoft в разделе **Вход**, затем загрузите официальный скин, выберите принадлежащий вам официальный плащ либо выполните сброс. Загрузка собственных официальных плащей недоступна. Кнопка **Обновить** повторно получает официальный профиль.

## Запуск и тестирование

Backend должен быть обновлён до 0.25.7 включительно, с рабочими миграциями PostgreSQL и настроенным локальным/S3-хранилищем текстур. Без публичного базового URL текстур Minecraft может не отображать назначенную локально хранимую текстуру, даже если предпросмотр Desktop работает. См. `texture-service.md`, `yggdrasil-authlib-injector.md`, `official-minecraft.md`.

```bash
cd apps/desktop
npm ci
npm run build               # Строгая проверка TypeScript и релизная сборка Vite
npm run test:textures       # API-клиент, разделение владения, CAS, 401/409, закрытые PNG, прогресс, смена официальной идентичности
npm run tauri:build         # Требуются платформенные зависимости Tauri
```

Задача `web` в CI выполняет сборку frontend и `test:textures`. В автономном контейнере без пакетов npm доступны лишь чистые тесты клиента TypeScript через глобальный `tsc`; полную проверку Tauri/браузера в этом случае следует фиксировать как **не выполненную**, а не считать успешной. Для production-сертификации дополнительно проверьте реальные локальное и S3-хранилища, загрузку/сброс с серверной политикой плащей, обновление входа и выход, предпросмотр 3D для скинов 64/128/256 и отображение в настоящем клиенте Minecraft с authlib-injector и в официальном сеансе.

Этот этап меняет только интерфейс Desktop; новые миграции БД и изменения существующей семантики текстур Backend не вводятся. Права Admin и эксплуатационные средства управления появятся в 0.25.9.
