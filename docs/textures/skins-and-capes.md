# Скины, плащи и текстуры

Backend содержит операции хранения и выдачи Minecraft-текстур. Публичное присутствие этих HTTP-методов **не доказывает**, что Desktop и Admin поддерживают завершённый сценарий загрузки, изменения и предпросмотра изображения.

## Административная модель

Проверяйте права пользователя на изменение texture, тип файла, максимальный размер, нормализацию PNG, допустимые размеры изображения, квоты, публичные URL и записи аудита. Не доверяйте присланному имени файла, MIME type и пути назначения.

## Интеграция клиента

Скин/плащ должен быть привязан к тому профилю/аккаунту, для которого клиент получает метаданные. После загрузки Desktop или Java runtime должен использовать актуальное подписанное/проверяемое описание текстур; конкретную цепочку проверяйте тестом с реальной игрой.

## Где искать реализацию

- `services/api/internal/httpapi/` — обработчики textures и соответствующие auth checks.
- `schemas/openapi.yaml` — публичный контракт маршрутов.
- `apps/admin/` и `apps/desktop/` — текущие интерфейсы.
- [Функции клиентского запуска](../clients/profiles-and-launch.md) и [модель доверия](../security/trust-model.md).

При запросе на расширение UI указывайте, что уже работает в API, а что требует нового пользовательского сценария. Не публикуйте изображения третьих лиц без разрешения.
