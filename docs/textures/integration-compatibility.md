# Launcher 0.25.12 — сертификация интеграции и совместимости текстур

Обновление добавляет **исполняемые** улучшения конкурентной работы PostgreSQL и сборщика мусора, проверку действительного профиля Yggdrasil/authlib-injector и PNG, реальное испытание жизненного цикла S3 и автоматизированную матрицу CI. Оно **не означает**, что игровой процесс Minecraft сертифицирован на платформе, где саму игру не запускали.

## Обновление и эксплуатационные изменения

- Развёртывайте бэкенд, исполняемый модуль обслуживания и интерфейс из **одной сборки 0.25.12**. Примените существующие миграции 0067–0074. **Миграции 0075 нет:** изменения 0.25.12 усиливают транзакционную работу с существующей схемой.
- Во время обновления остановите старые процессы `texture-maintenance` сборщика мусора. Новая команда удерживает `FOR UPDATE` на записи объекта от физического удаления до окончательного удаления из PostgreSQL. Под блокировкой проверяются действующие назначения, сохранённые элементы библиотек, значения проекта по умолчанию и резервные текстуры, семидневная история и активные привязки резервных копий. Запись, использующая внешний ключ, должна ждать; при неуспешном удалении из хранилища транзакция БД откатывается. Не используйте старые процессы очистки одновременно с GC 0.25.12.
- Выделите учётную запись PostgreSQL только с необходимыми правами обслуживания; не включайте данные доступа к локальному хранилищу или S3 в отчёты и исходный код.
- Регулярно создавайте **согласованные резервные копии PostgreSQL и объектов текстур**. Снимка только PNG недостаточно для восстановления владельцев, назначений и ревизий.

## Воспроизводимые команды проверки

Запускайте из корня репозитория:

```bash
python3 scripts/version/manage.py check
python3 scripts/contracts/validate-openapi.py
cd services/api
go test -race -count=1 ./internal/storage ./internal/texturepng ./internal/texturefetch ./internal/yggdrasiltexture ./internal/officialminecraft ./cmd/texture-compat-02512
go build -o /tmp/texture-compat ./cmd/texture-compat-02512
go build -o /tmp/texture-maintenance ./cmd/texture-maintenance-0253
```

Для **реального интеграционного испытания PostgreSQL** укажите переменные окружения `TEST_PG_DSN_0251`, `_0252`, `_0253`, `_0254`, `_0255`, `_0259`, `_02510`, `_02511`, направленные на **одноразовую БД PostgreSQL 17 или новее**. Не используйте промышленную БД: тесты создают и удаляют схемы. Выполните:

```bash
go test -race -count=1 -timeout 12m ./internal/repository ./internal/httpapi
```

Тест 0.25.12 проверяет, что второй сеанс SQL не может добавить ссылку внешнего ключа, пока очистка удерживает блокировку удаляемого объекта. Также проверяются неуспешный обратный вызов хранилища, просроченная аренда и отклонение повтора.

Для **реального S3** задайте `TEST_TEXTURE_S3_ENDPOINT_02512`, `TEST_TEXTURE_S3_BUCKET_02512`, `TEST_TEXTURE_S3_ACCESS_KEY_02512`, `TEST_TEXTURE_S3_SECRET_KEY_02512` для изолированного одноразового бакета и выполните:

```bash
go test -race -count=1 ./internal/storage -run TestTextureRealS3Lifecycle02512 -v
```

Тест действительно создаёт неизменяемый объект, повторяет условную операцию PUT, сверяет дайджест, создаёт резервную копию, удаляет с условием ETag, восстанавливает из снимка и проверяет байты восстановленного объекта. В CI используется MinIO. Если адрес S3 не задан, тест пропускается **без заявления об успешной сертификации**.

Проверка Desktop и Admin:

```bash
(cd apps/desktop && npm ci && npm run test:textures && npm run build)
(cd apps/admin && npm ci && npm test && npm run build)
```

## Проверка действительного Yggdrasil/authlib-injector

Выберите **локальный Minecraft UUID лаунчера** с активным публичным управляемым PNG-скином. Укажите рабочий HTTPS-адрес API и запустите:

```bash
cd services/api
go run ./cmd/texture-compat-02512 \
  --origin https://launcher.example.com \
  --uuid 12345678-1234-4234-9234-0123456789ab \
  --expect-skin=true --expect-cape=false
```

Средство проверяет:

1. Актуальные метаданные корневого адреса: действительный открытый ключ RSA не короче 2048 бит и разрешённый список доменов с адресом сервера.
2. Настоящий ответ `sessionserver/session/minecraft/profile/{uuid}?unsigned=false`, идентификатор и имя профиля, ровно одно свойство `textures` и его действительную подпись RSA/SHA1withRSA, проверенную ключом из метаданных.
3. Подписанные данные Base64, совпадающие с тем же локальным профилем, и корректные метаданные модели `slim` или модели по умолчанию. Подстановка официальных UUID Minecraft запрещена.
4. Реальные запросы управляемых PNG только к тому же адресу API, путь с дайджестом, отсутствие перенаправлений и параметров URL/учётных данных, ограничение ответа в 4 МиБ, совпадение SHA-256, полную проверку чанков PNG, распаковку и геометрию Minecraft.

Средство выводит единственный JSON-результат только при успехе; любая ошибка совместимости даёт ненулевой код возврата. Параметр `--expect-cape=true` требует опубликованного локального плаща. На буквальном локальном тестовом сервере допустим `--allow-loopback-http`, но в рабочем окружении **никогда** не используйте его и не отключайте проверку сертификатов.

Эта проверка исследует ответы протокола и байты, **а не реальное отображение в игре**. Она не авторизует аккаунты Microsoft, не запускает Minecraft и не переопределяет списки разрешённых адресов.

## Условия CI

В `.github/workflows/texture-certification-02512.yml` входят:

- Полные сборки Go API, модуля обслуживания и импортёра Gravit, проверки гонок и `vet` с **реальным контейнером PostgreSQL 17** и всеми DSN интеграционных испытаний текстур.
- **Настоящий MinIO** для условной записи, жизненного цикла объектов и восстановления.
- Тесты npm для Desktop и Admin и промышленные сборки интерфейса.
- Необязательная проверка действительного HTTPS-профиля с подписью и PNG, запускаемая оператором (параметры `workflow_dispatch`: `texture_origin`, `local_minecraft_uuid`).

Для обычных запросов на изменение проверка действительного сервиса необязательна: для каждой копии репозитория не существует отдельного развёртывания. **При сертификации выпуска** её нужно выполнить на кандидате и сохранить успешный журнал. Пропущенную задачу нельзя выдавать за выполненный тест реального сервиса.

## Оставшиеся обязательные условия перед выпуском 0.26.0 GA

Эти испытания требуют настоящих аккаунтов и оборудования владельца; их **нельзя** подтвердить модульными тестами репозитория или имитациями сервисов:

| Испытание | Требуемое подтверждение |
| --- | --- |
| Локальный аккаунт (Vanilla, Fabric, NeoForge; поддерживаемые Minecraft и Java) | Реальный запуск, видимые второму клиенту скин и плащ, снимок экрана и идентификаторы сеанса/профиля в журнале без токенов |
| `classic` и `slim` | Правильная геометрия персонажа в игре после изменения модели; проверка нового сеанса и переподключения |
| Desktop в Windows, macOS, Linux | Снимки галереи, 2D/3D-просмотра, прогресса, загрузки/отмены/выбора/сброса/удаления, конфликта 409 и обработки ошибок |
| Официальный аккаунт Microsoft | Сквозной OAuth-вход в собственный аккаунт; загрузка/сброс официального скина и выбор только принадлежащих аккаунту плащей; без повторного использования локального удостоверения или подписи |
| Приватность и авторизация | Блокировка чужого UUID, чужого дайджеста текстуры, отозванных прав на плащ, неправильного или слишком большого PNG, приватной текстуры и запрещённого URL |
| Настоящее объектное хранилище | Проверки ETag/условного DELETE, восстановления резервной копии и сброса кэша у выбранного S3-провайдера с опубликованным скином |
| Восстановление после сбоя | Восстановление PostgreSQL и объектов из согласованного снимка; остановленные старые GC-процессы и отсутствие висячих ссылок библиотеки |

**Выпуск нельзя считать сертифицированным, пока эти наблюдения не зафиксированы в действительности.** Успех CI необходим, но не доказывает полную кроссплатформенную матрицу игрового процесса Minecraft. Не сохраняйте в артефактах процесса CI настоящие токены авторизации, закрытые ключи RSA или персональные данные.
