# Launcher 0.22.9 — возможности настольного приложения

## Рабочие функции

- Настольное приложение сохраняет в локальном `config.json` настройки Java, оперативной памяти, разрешения и полноэкранного режима, автоматического подключения, идентификатор сервера ServerBridge, публичный игровой адрес и порт, а также `offlineEnabled`. При чтении конфигурации версии 0.22.8 используются безопасные значения по умолчанию.
- Настройки памяти, окна и подключения к серверу проверяются в интерфейсе и в Rust, после чего преобразуются в аргументы настоящего процесса Java. Пользовательские параметры не изменяют и не переподписывают манифесты версий v1/v2.
- Нативная среда выполнения ограничивает `-Xmx` разрешённым подписанной политикой диапазоном, передаёт пути к классам и модулям с помощью массивов аргументов без интерпретации командной оболочкой и применяет список разрешённых переменных окружения.
- **Выбор серверов в рамках проекта и профиля:** `GET /api/v1/projects/{projectId}/profiles/{profileId}/servers` возвращает безопасный список активных узлов только нужного проекта и профиля. Секреты идентичности узлов и внутренние сведения о маршрутизации не передаются. Получение списка не даёт права подключиться: фактическое подключение через ServerBridge по-прежнему требует действующего серверного билета и обязательной аттестации.
- Идентификатор узла ServerBridge не является игровым DNS-именем или портом Minecraft. Для автоматического подключения пользователь задаёт действительный публичный адрес игрового сервера. В Minecraft 1.20 и новее применяется Quick Play; в более ранних версиях — `--server` и `--port`. Одноразовый билет ServerBridge запрашивается до автоматического подключения, чтобы клиент не начал вход раньше подтверждения права доступа. Если сервер требует аттестацию Continuous Guard Attestation v2 после запуска, предварительное подключение нельзя подтвердить: автоматическое подключение отклоняется, но обычный запуск и ручное подключение остаются доступными. Автоматический выбор Quick Play для нестандартных версий загрузчиков требует отдельной сквозной проверки.

## Автономный режим

Автономный запуск допускается **только** для подписанного манифеста v2, в котором издатель явно разрешил `runtime.launch.offlineMode`. Манифест сохраняется в локальный кеш после проверки подписи Ed25519 по закреплённому ключу и повторно проверяется при чтении и непосредственно перед запуском. Значения `projectId/profileId/channel/version/signature` должны совпадать с кешированными. Перед запуском среда выполнения ещё раз проверяет целостность файлов. Автономный режим не выдаёт игровую сессию Minecraft, билет запуска Guard или разрешение на вход через ServerBridge. Он не позволяет входить на защищённые сетевые серверы и не отключает ограничения процессов Guard.

## Ограничения сертификации

Необходимы сквозные проверки на Windows, Linux и macOS, проверка ServerBridge с настоящей PostgreSQL, проверка Quick Play для всех заявленных версий загрузчиков и промышленная сборка Rust/Desktop в полностью подготовленной среде CI. Без этих проверок реализация не считается сертифицированной для промышленной эксплуатации.
