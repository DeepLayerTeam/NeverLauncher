# Эксплуатация и операции

## Что контролировать

- Доступность `/health`, `/ready`, серверной части, Redis и PostgreSQL и состояние миграций.
- Заполнение хранилища, очереди задач/событий расширений и статус ServerBridge-узлов.
- Ошибки удостоверений, подозрительные сессии, аудит действий администратора и выпуска релизов.
- Согласованность версий, сертификаты точного коммита и сроки действия ключей/сертификатов.

## Управление через CLI

CLI поддерживает `nl operations status|readiness|diagnostics|diagnostics-bundle`, `nl adminops ...`, `nl backup ...`, `nl db ...`; для серверных сценариев указывайте `--backend <url>` и авторизованный токен. Точный перечень команд — `cli/cmd/neverlauncher/main.go` и [справочник](../reference/cli.md).

## Резервные копии

Планируйте согласованный снимок PostgreSQL и файлового хранилища, проверяйте тестовое восстановление и совместимость версий миграций. `nl backup create|inspect|restore-dry-run|restore` реализует отдельные операции, но **пробное восстановление (`dry-run`) не заменяет тест реального восстановления**. Храните резервные копии отдельно от среды исполнения и защищайте от удаления скомпрометированным приложением.

## Службы

Docker Compose: `deploy/production/docker-compose.yml`; systemd: `deploy/systemd/neverlauncher-api.service`; nginx: `deploy/production/nginx.conf`. Настройка обратного прокси и TLS зависит от инфраструктуры. Разрешайте сервисные порты минимальному набору сетей и проверяйте готовность API до подключения Desktop.

См. [развёртывание в промышленной среде](../getting-started/production.md) и [обновления](../migration/upgrade.md).
