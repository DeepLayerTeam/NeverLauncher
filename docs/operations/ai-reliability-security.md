# AI Reliability & Security (1.2.5)

Обновите Backend и оба клиента одновременно. Новых миграций и переменных окружения нет. Существующие бюджеты, авторизация, MFA и подтверждения Copilot не изменяются.

- Сервер принимает ровно один JSON-объект с единственным полем `prompt`. Распознаваемые ключи OpenAI/GitHub/AWS, JWT, приватные ключи, Bearer и типовые присваивания паролей/токенов отклоняются с HTTP 422 до резервирования бюджета. Проверка также выполняется в клиентах; Desktop не добавляет распознанный секрет из предыдущих сообщений в новый контекст. Это эвристика, не полноценная DLP: произвольные секреты, обфускация и персональные данные могут не распознаться. История Desktop остаётся локальной и незашифрованной; удалите старые чувствительные диалоги вручную.
- Запрос OpenAI содержит `store:false`, `tools:[]`, `tool_choice:none`. Это не гарантия zero data retention у провайдера. AI не получает административных токенов или прямого доступа к API. Copilot сохраняет серверную проверку, RBAC/MFA и подтверждение человеком.
- Неизвестные SSE-события и инструментальные output items прерывают поток. Лимит текста ответа — 128 КиБ. При неизвестном usage сохраняется полный резерв. Не повторяйте платный запрос автоматически.
- HTTP 429 открывает локальный circuit breaker на 30–300 секунд с учётом Retry-After; три последовательных отказа провайдера также открывают его. После паузы допускается один запрос для проверки восстановления. Новые запросы в паузе получают 503 без резерва; текущие запросы могут завершиться. Gate действует на экземпляр Backend; SQL-бюджет остаётся общим. Клиентское прерывание не считается отказом провайдера.
- Проверка действительности сессии выполняется с периодом около 5 секунд даже при отсутствии данных от провайдера, и перед подтверждением завершения. При отзыве поток отменяется, неизвестные расходы не освобождаются.

Проверки: `go test -race ./internal/aigateway` в `services/api`, `npm test` в `apps/admin`, `npm run test:ai-chat` и `npm run test:ai-diagnostics` в `apps/desktop`. Существующие AI workflows запускают эти тесты и сборки. Перед production-развёртыванием необходимо пройти их и проверить контролируемый запрос с реальным OpenAI API. Не вставляйте настоящие ключи в тестовые prompts.
