# AI Diagnostics — NeverLauncher 1.2.3

## Работа с диагностикой

1. Откройте **Диагностика и поддержка** (вход не требуется) или **AI-чат → Анализ ошибок и журналов**.
2. Выберите тип журнала и до пяти текстовых файлов UTF-8: `logs/latest.log`, `crash-reports/*.txt`, `hs_err_pid*.log`, журнал процесса (путь отображается в разделе «Журналы») или журнал модов/загрузки. Можно анализировать состояние лаунчера без импорта файлов. Сжатые `.gz`/ZIP и двоичные файлы не принимаются; предварительно распакуйте лог локально.
3. Нажмите **Анализировать состояние и журналы**. Локальный анализ учитывает до 80 последних записей журнала лаунчера, результат проверки Java, последнюю загрузку/текущий статус передачи, состояние запуска и ошибки проверки файлов. Эти данные относятся к наблюдаемому состоянию приложения и могут содержать признаки предыдущей операции или другого профиля. Выбранные логи должны относиться к диагностируемой ошибке.
4. Прочитайте вероятные причины и безопасные проверки. Локальный отчёт работает без сети. Наличие маркера не доказывает причину; отсутствие маркеров не означает, что ошибок нет.
5. Для дополнительного анализа через OpenAI войдите в аккаунт, проверьте точный отчёт, подтвердите подготовку запроса и нажмите **Подготовить запрос AI**. В AI-чате открывается новый черновик без предшествующего контекста; при необходимости отдельно включите метаданные проекта. Подтвердите согласие на отправку и нажмите **Отправить**. Используется имеющийся AI Gateway: авторизация, бюджет, лимиты, потоковая выдача, остановка генерации, история и учёт расходов. При отключённом AI, недоступной сети или исчерпанном бюджете локальный анализ остаётся доступным.

## Поддерживаемые сигналы

- Java: отсутствие/несовместимая версия, ошибки опций JVM, heap и native memory, нативные падения.
- Minecraft: графика/OpenGL, ошибки запуска и данных мира.
- Модификации: несовместимые зависимости, конфликт дубликатов, Mixin, ошибки загрузки классов/API.
- Загрузки: сеть/DNS, TLS, HTTP-отказы, недоступные ресурсы, подписи и контрольные суммы, повреждённые архивы.
- Launcher: авторизация, диск, права, проверка управляемых файлов и другие сообщения об ошибках.

Проверки возвращают фиксированные идентификаторы признаков, числа совпавших строк (не количество уникальных аварий), рекомендации и ограниченные числовые статусы. Разные журналы могут описывать один сбой. Отчёт не устанавливает точное имя неисправного мода: оно намеренно не извлекается в передаваемые данные.

## Приватность и ограничения

Файлы выбираются через системный механизм выбора файлов WebView, без предоставления приложению произвольного IPC-доступа к файловой системе. Для каждого выбранного файла читается максимум 576 КиБ: до 64 КиБ с начала и 512 КиБ с конца; неполные пограничные строки отбрасываются. Строки анализируются в пределах 8192 символов, максимум 100 000 непустых строк на источник. Частичный анализ отмечен в интерфейсе. Сырые строки и имена файлов не входят в генерируемый отчёт и не записываются в историю диагностики. Импортированные признаки находятся в памяти экрана, удаляются кнопкой очистки/при смене области или выходе с экрана. Переданный в чат черновик привязан к области сессии, проекта, профиля, канала и каталога. После отправки вопрос и AI-ответ могут остаться в обычной локальной **незашифрованной** истории чата, которую можно удалить. Отдельно введённый пользователем текст отправляется по правилам AI-чата; не вставляйте в него сырые приватные логи, секреты или персональные данные.

Диагностика не запускает команды, не скачивает моды, не исправляет файлы автоматически и не изменяет действующие механизмы доверия. Сбой подписи или TLS требует штатной проверки/ремонта, а не обхода защиты. Перед работой с миром сделайте резервную копию. Действующие диагностика поддержки и Sentry не заменяются AI-диагностикой.

## Проверки

```sh
cd apps/desktop
npm ci
npm run test:ai-diagnostics
npm run test:ai-chat
npm run test:diagnostics-support
npm run build
```

CI: `ai-chat-workspace.yml`, `diagnostics-support.yml`, `release-candidate.yml`. Локальные тесты включают реальные Blob-файлы, предел чтения, классификацию, обезличивание, отсутствие инъекции исходного текста, допустимый размер отчёта и HTTP/SSE с локальным тестовым сервером. Для нативной приёмки проверьте выбор логов и отправку отчёта из Tauri на Windows, Linux и macOS с настроенным AI Gateway, в том числе режим без входа и отказ при исчерпанном бюджете. Реальные ответы OpenAI зависят от модели и не являются подтверждением диагноза.
