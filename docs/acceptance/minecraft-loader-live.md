# NeverLauncher 0.52.4 — нативная совместимость Minecraft и загрузчиков в многопользовательском режиме

Это **действующее условие допуска по работе Runtime**, а не заявление, будто все 280 обязательных конфигураций уже прошли испытания. Существующая матрица совместимости запускает настоящий клиент с необходимыми ОС, процессором, JDK и загрузчиком. Начиная с 0.52.4, **для каждой обычной цели `client` также требуются доказательства реального подключения** к выделенному серверу Minecraft точно соответствующей версии. Пять существующих целей Vanilla с соответствующим сервером и пять сквозных интеграционных целей сохраняют свои отдельные более глубокие проверки.

## Подготовка проверенных серверных исполняемых файлов

Приёмочная проверка использует существующий механизм запуска закреплённого настоящего сервера `staged_matching_0344.MatchingServer` с выделенным изолированным сервером на `127.0.0.1`. Для Vanilla авторитетный сервер загружается и проверяется по SHA-256 через `nl runtime vanilla-server`. Если upstream не предоставляет сервер для старой версии Minecraft, а также **для всех модифицированных загрузчиков**, оператор обязан подготовить полный протестированный ZIP серверного дистрибутива, его SHA-256 и явно указать точную разрешённую версию загрузчика. В архиве точка входа должна располагаться в его корне: для Fabric/Quilt обычно `server.jar`, для Forge/NeoForge часто `run.sh` или `run.bat` (можно явно задать `serverEntry`). Для поддерживаемых модифицированных серверов эта проверка совместимости не требует отдельного плагина ServerBridge — для него существует собственная матрица из 14 реальных целей.

Укажите `LAUNCHER_E2E_SERVER_PINS=/absolute/path/pins.json` и `LAUNCHER_E2E_SERVER_BUNDLE_DIR=/absolute/path/zips`. GitHub Actions берёт те же значения из переменных репозитория `LAUNCHER_E2E_SERVER_PINS_PATH` и `LAUNCHER_E2E_SERVER_BUNDLE_DIR`; на размещённых исполнителях файлы должны быть подготовлены оператором заранее (например, в независимо проверенном репозитории артефактов или кеше). Отсутствие кеша, материалов подписи, установленного JDK, графического окружения Desktop или серверного исполняемого файла означает **BLOCKED**, а не успешный тест. Не размещайте в этих артефактах учётные данные и конфиденциальные данные игровых миров.

В файле закреплённых параметров должны присутствовать `schema: neverlauncher.compatibility-server/0.52.4` и объект `targets` с ключами, точно совпадающими с **идентификаторами целей матрицы**. Каждая запись содержит `minecraft`, `loader`, `loaderVersion` (точную версию, никогда `latest`), `file` (простое имя ZIP), `sha256` (64 строчных шестнадцатеричных символа) и необязательный `serverEntry` (простое имя файла в корне). Для Vanilla с опубликованным Mojang проверяемым сервером файл не требуется. Вспомогательная программа отклоняет символические ссылки, выход за границы пути, несовпадения хешей, скрипты неподходящей ОС, отсутствующие метаданные и неожиданные версии сервера/загрузчика. Это доверенный исполняемый код оператора: запускайте только на изолированных одноразовых исполнителях.

## Фактическое выполнение

1. Обычный E2E-скрипт подготавливает и проверяет клиент Mojang либо точно заданный загрузчик; проверяются закреплённый файл разрешённых зависимостей и classpath. Исполнитель совместимости проверяет идентичность Java (основная версия, производитель и SHA-256 исполняемого файла), ОС и архитектуру.
2. Координатор реальных испытаний запускает **настоящую выделенную JVM Minecraft** на основе проверенного серверного JAR либо закреплённого дистрибутива, подтверждает старт, точную версию Minecraft и разрешённую версию загрузчика (если применимо), а также игровые такты через аутентифицированный локальный RCON.
3. Настоящий Runtime запускает подготовленный клиент с параметрами `--server 127.0.0.1 --server-port <ephemeral>` (либо Quick Play в новых версиях). Клиент должен фактически подключиться; отображение главного меню или истечение тайм-аута без подключения не считается успехом.
4. Во время подключения клиента координатор фиксирует настоящее имя игрока в серверном журнале **и** дважды в списке `list` через RCON, одновременно проверяя увеличение счётчика тактов мира. После завершения клиента он посылает серверу настоящую команду `stop` по RCON, требует успешного завершения JVM и вычисляет хеши **финального** консольного журнала и сертификата клиента. Подтверждения готовности, присутствия игрока и корректной остановки также привязаны к исходному коммиту, запуску CI и номеру попытки.
5. Исполнитель матрицы проверяет `live-join.json`, `live-server-ready.json`, `live-server-witness.json`, `matching-server.log`, идентичность закреплённого сервера, сертификат клиента и хеши. Агрегатор матрицы и реестр приёмки независимо повторно проверяют те же исходные файлы. Испорченные, повторно использованные, несоответствующие или отсутствующие доказательства приводят к `FAIL`/`BLOCKED`.

### Запуск одной целевой конфигурации на нативном узле

Задайте стандартные переменные окружения, уже используемые в `.github/workflows/compatibility.yml`: `LAUNCHER_COMPAT_TARGET_ID`, `LAUNCHER_COMPAT_OS`, `LAUNCHER_COMPAT_ARCH`, `LAUNCHER_COMPAT_SCOPE=client`, `LAUNCHER_E2E_MINECRAFT_VERSION`, `LAUNCHER_E2E_LOADER`, `LAUNCHER_E2E_LOADER_VERSION`, `LAUNCHER_E2E_JAVA_MAJOR`, `LAUNCHER_E2E_JAVA`. Для целей с загрузчиками подготовьте закреплённые архивы, как описано выше, и запустите:

```bash
bash e2e/scripts/run-compatibility-case.sh
```

Для настоящего графического клиента на Linux нужны Mesa/OpenGL и Xvfb; на Windows/macOS он должен запускаться в активном графическом сеансе с необходимым оборудованием и графическими возможностями. CI выделяет до 90 секунд на цель клиентского уровня. Авторизация официального аккаунта Microsoft, подписание релизных установщиков и проверенная доставка конечных пакетов — отдельные условия выпуска 0.53.0. Этот локальный сценарий совместимости использует только изолированного тестового игрока в автономном режиме и не сертифицирует промышленную авторизацию.

**Статус условия допуска:** при подготовке 0.52.4 не запускались нативная матрица Minecraft на 280 целей, закреплённые серверные дистрибутивы загрузчиков, реальные входы аккаунтов и внешняя проверка конечных пакетов. Успешный модульный тест не равен запуску игры; GA версии 0.53.0 остаётся `BLOCKED`.
