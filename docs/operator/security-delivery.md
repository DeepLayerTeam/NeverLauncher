# Секреты, подписи, API/SDK, миграция

## Работа с секретами

- `deploy/production/.env`, закрытый ключ TLS, материал закрытого ключа подписи Ed25519, токен первичной настройки, ключ восстановления, учётные данные S3/PostgreSQL/Redis и секреты внешних провайдеров — разные объекты, с раздельной ротацией и запретом публикации в Git/CI/ZIP диагностики.
- `minimal backup-portable` включает конфигурацию и секреты **внутри зашифрованного архива**, но ключ восстановления хранится отдельно. Standard/Network-HA DR **не** сохраняет автоматически `.env`, TLS и ключи; возвращайте их из доверенного хранилища секретов.
- Потеря доверенного корневого ключа подписи без контролируемой ротации может нарушить доверие существующих клиентов. Слепая генерация новых ключей после восстановления не является восстановлением.
- Оператор проверяет права `0600` приватных файлов, системные сертификаты CA, имя узла и срок действия сертификата; не использует `curl -k` и не отключает проверку сертификата TLS.

## Подписанный выпуск

Сначала реальная сборка и платформенная подпись, затем окончательная упаковка, проверка **конечных байтов**, независимые результаты проверки среды выполнения и готовности выпуска, BOM, SPDX 2.3 SBOM, сведения о происхождении сборки по SLSA, манифест выпуска и подпись. Шесть целей: Windows/Linux/macOS × x64/ARM64. Проверка Linux не подтверждает Windows/macOS. Отсутствующий сертификат, подпись, физический исполнитель CI или сквозной игровой тест — выпуск заблокирован.

Проверяйте CLI `launcher release distribution-verify` и `launcher release verify` по [Signed Distribution](../releases/0.45.11-signed-distribution.md). Для брендирования сохраняйте идентичность проекта и закреплённый корневой ключ доверия по [Branding GA](../releases/0.45.10-branding-ga.md). Установщик не должен автоматически переключаться на новый выпуск при ошибке подписи или запуска.

## API/SDK

Канонический `schemas/openapi.yaml`: OpenAPI 3.1.1, контракт `1.0.0`, 452 операции из базовой версии 0.45.12. `sdk/api/go`, `sdk/api/typescript`, `sdk/java/http-client` отправляют реальные HTTP-запросы; это **не** 452 полностью типизированных индивидуальных методов. Обратная совместимость с 0.45.11 требует проверки на работающей системе (сравнение OpenAPI и мок-запросы недостаточны). [API/SDK Freeze Candidate](../releases/0.45.12-api-sdk-freeze-candidate.md).

```sh
python3 scripts/contracts/validate-openapi.py
python3 scripts/contracts/compatibility.py
python3 scripts/sdk/generate-http-operations.py --check
```

## Миграция Gravit

Перед миграцией проведите инвентаризацию и пробный запуск, зафиксируйте поддерживаемые средства проверки паролей, UUID, OptionalView и модули. Старые Gravit-сессии, незнакомые хеши и произвольные сторонние JAR нельзя автоматически объявлять совместимыми. Перед переключением нужен восстановимый снимок состояния и проверка реального подключения к серверу Minecraft и явная точка возврата. [Runbook Gravit Migration GA](../migration/gravit-migration-ga.md).
