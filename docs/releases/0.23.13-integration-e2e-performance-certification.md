# NeverLauncher 0.23.13 — Integration, E2E & Performance Certification

## Исполняемые инструменты

- `scripts/certification/fault_server.py`: управляемый loopback HTTP-сервер с обрывами, Range/ETag, неправильным 206, 416, 429/Retry-After, 503, подменой и задержкой. Реальный HTTP, реальные байты, не mock функций NeverRuntime.
- `test_fault_server.py`: 10 тестов поведения самого fault-сервера.
- `runtime/neverruntime/examples/cert_sign_fixture.rs`: временный Ed25519 подписыватель тестовых JSON через настоящий `neverruntime::sign_manifest`; не включает приватных production-ключей.
- `scripts/certification/runtime_e2e.py`: настоящий `neverruntime sync-local` с подписью, подменённым зеркалом, сверкой файлов и вторым профилем полностью offline. Не пройдёт без рабочего Rust-исполняемого файла.
- `scripts/certification/benchmark.py`: минимум три попарных запуска **реального NeverRuntime 0.23.0** и текущего NeverRuntime с одинаковыми файлами, ограничениями стенда и измерением фактических wire bytes. Нельзя подменять baseline Python-скриптом, а сравнение с Gravit — отдельное исследование.
- `scripts/certification/certify.py`: обязательные Rust/Go test cases, evidence привязан к exact Git SHA, дополнительно вычисляется SHA-256 дерева файлов; `SKIP`, отсутствующий тест, Cargo или недоступный реальный E2E — **не успех**.
- `cli/cmd/neverlauncher/cert_windows_locks_02313_windows_test.go`: настоящий Windows sharing violation с экслюзивной блокировкой `.exe`.

## Воспроизведение

```bash
python3 scripts/version/manage.py check
python3 -m unittest discover -v -s scripts/certification -p test_fault_server.py
python3 scripts/certification/certify.py --mode local --output dist/certification-02313/evidence.json

# Для строгой production сертификации из чистого Git checkout:
export NEVERLAUNCHER_BASELINE_0230_BIN=/abs/path/to/compiled/neverruntime-0.23.0
export NEVERLAUNCHER_CERT_JAVA_EVIDENCE=/abs/path/to/real-java.json
export NEVERLAUNCHER_CERT_BOOTSTRAP_EVIDENCE=/abs/path/to/real-clean-install.json
export NEVERLAUNCHER_CERT_POWERLOSS_EVIDENCE=/abs/path/to/powerloss.json
export NEVERLAUNCHER_CERT_WINDOWS_LOCK_EVIDENCE=/abs/path/to/windows-lock.json
python3 scripts/certification/certify.py --mode full --output dist/certification-02313/evidence.json
```

Отчёты внешних систем допускаются только с `status=passed` и **точно тем же** commit SHA. Внешние отчёты предоставляются организационным доверенным CI; JSON сам по себе не является криптографической аттестацией. Evidence для всех платформ нужно собрать на *одном* исходном commit. Сертификационные тесты с fake Java/Runtime не заменяют установку настоящей Java и запуск Minecraft на чистой ОС. Внешнее power-loss испытание должно реально завершать виртуальную машину во время filesystem commit, а не только завершать тестовый процесс. Требуется сохранить VM image/снимки и сценарий запуска.

### Статус release gate

Версия 0.23.13 **не становится автоматически сертифицированной**, когда запускаются только Python или Go тесты. Для GA требуется полная матрица Windows/Linux/macOS x64/ARM64 в объёме заявленных платформ, подписанные production installer/Java, реальный cold-install → launch Minecraft, fault scenarios, reboot/power-loss, baseline Never 0.23.0 и отдельное сравнение с Gravit, если оно заявлено. Извлечённый ZIP без `.git` может получить только `sourceTreeSha256`, а не подлинный `commit SHA`.
