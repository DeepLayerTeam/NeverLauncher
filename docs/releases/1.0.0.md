# NeverLauncher 1.0.0

> **Согласованный исходный выпуск и строгий допуск на шести платформах.** Версия включает исполняемые механизмы проверки окончательных установщиков, подписанных подтверждений и независимой приёмки реальных игровых сценариев.

**Тип документа:** описание выпуска · **Версия исходников:** `1.0.0` · **Состояние:** кандидат на общедоступный выпуск, не объявленный сертифицированным без независимых свидетельств

## Главное в версии

В `1.0.0` основной акцент сделан на **воспроизводимости и достоверности выпуска**: готовые установщики нельзя считать допущенными к публикации, пока не подтверждены их фактические байты, нативные проверки и обязательные испытания для точного исходного коммита.

| Направление | Что вошло в исходники |
| :--- | :--- |
| **Единая версия** | Согласование продуктовых пакетов Admin, Desktop, CLI, Runtime и Guard с `VERSION=1.0.0` |
| **Независимая приёмка** | Требование подписанного исполнения E2E-01–18 и подтверждений финальных установщиков |
| **Проверка пакетов** | Привязка файлов к SHA-256 и размеру; повторная проверка перед выпуском |
| **Подготовка поставки** | `publication_ga.py stage` контролирует перенос подлинных пакетов и откатывает частичный перенос при ошибке |
| **Подписанный состав выпуска** | Обязательные файлы включаются в `RELEASE_MANIFEST.json`, защищённый `SHA256SUMS` и подписью |
| **Защита публикации** | Перед публикацией повторяются проверки независимых свидетельств, CI, манифеста и окончательных байтов |

Источник подробностей: [история изменений](../../CHANGELOG.md) и [нормативная приёмка](../acceptance/supported-platform-ga-1.0.0.md).

## Для кого этот выпуск

**Владельцам проектов** — единая продуктовая основа для проектов, профилей и каналов распространения Minecraft-клиентов.  
**Операторам** — проверяемая процедура допуска конкретной поставки, а не доверие одному названию версии.  
**Разработчикам** — явные условия, при которых недостающая проверка или изменённый установщик блокирует выпуск.

Это обзор предусмотренных возможностей. Сквозная работоспособность конкретной установки не объявляется без соответствующего результата испытаний.

## Шесть целевых платформ

Все перечисленные варианты — **цели независимой сертификации**, а не заявление об успешной поддержке.

| Операционная система | Архитектура | Формат финального пакета |
| :--- | :--- | :--- |
| Windows | x64 | `.exe` |
| Windows | ARM64 | `.exe` |
| Linux | x64 | `.deb` и отдельная подпись `.asc` |
| Linux | ARM64 | `.deb` и отдельная подпись `.asc` |
| macOS | x64 | `.pkg` |
| macOS | ARM64 | `.pkg` |

Финальная проверка подписей Windows/macOS и фактического запуска выполняется на соответствующих нативных исполнителях. Проверки на Linux не заменяют эти испытания.

## Что обязательно проверить перед выпуском

1. Подтверждён **один точный коммит**; исходный индекс и восемь конечных файлов (шесть пакетов и две отдельные подписи Linux) соответствуют закреплённым SHA-256.
2. Независимый исполнитель подтвердил **E2E-01–18**, включая реальные аккаунты, игру, публикацию, установку, восстановление и защитные сценарии.
3. Выполнены остальные обязательные игровые, платформенные, эксплуатационные и проверочные сценарии из нормативной процедуры.
4. Независимые ключи и подписи одобрения проверены; они не подменены тестовыми фикстурами или значениями из недоверенного отчёта.
5. Все обязательные задания CI для того же коммита успешно завершены; отсутствуют открытые блокирующие дефекты P0/P1.
6. Сформирован и проверен подписанный состав выпуска; публикация разрешена только после повторного контроля конечных байтов.

## Известные ограничения

- **Сертификат не включается автоматически в исходный архив.** Наличие кода проверки не равно выполненному независимому тестированию.
- **Матрица совместимости не означает успех всех сочетаний** Minecraft, JVM и загрузчиков. Для конкретной цели нужны действительные результаты реальных испытаний.
- **Официальная аутентификация, выбор дополнительных модов и другие пользовательские пути** требуют проверки сквозной реализации для этой версии; наличие API не является гарантией готового интерфейса.
- **Развёртывание не равно отказоустойчивости.** Физическое разделение узлов, восстановление и работа с реальными секретами проверяются отдельно.
- **Minecraft и учётные записи не входят в поставку исходников.** Используйте законные экземпляры игры и предусмотренные способы входа.
