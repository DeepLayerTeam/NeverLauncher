# 0.33.0 — Single-Node GA certification boundary

Release source version: `0.33.0`.

The release signing and verification path now requires an independent Ed25519
operator report plus a same-commit, real 0.33.0 RC test receipt. The report
must cover a **real installed SQLite-only HTTP Backend**, durable coordinator,
authentication, Minecraft join, replay, backup/restore, upgrade rollback,
capacity, single owner and fail-closed security. These files are mandatory
in the signed BOM/release manifest.

**Not a certified GA claim:** as of the input 0.32.16 codebase, the main HTTP
Repository still uses PostgreSQL. The new gate therefore blocks production
Single-Node GA until the missing runtime work and externally approved actual
acceptance tests exist. A code version number, locally passing unit tests, or
an automatically created certificate does not change that fact.

See `docs/operations/single-node-ga-0330.md` for deployment support boundaries,
runbook, test requirements, release commands and independent trust setup.
