# NeverLauncher 0.27.4 — MirrorHelper Command Parity

0.27.4 adds **executable CLI operations** on the existing Client Factory
0.27.1–0.27.3 materializers, immutable InstallPlan and subprocess worker.
It is not an implementation of the GravitLauncher Java module or an untrusted
shell-workspace interpreter. Names are command-level equivalents, and explicit
SHA-256 verification takes precedence over auto-downloading unknown bytes.

## Supported operations

| Factory CLI subcommand | Execution semantics |
| --- | --- |
| `install-client` | Actual `client-factory build` for Vanilla, Fabric, Quilt, Forge or NeoForge. |
| `install-mods` | Download/copy exact `mods/*.jar` from local manifest or an exact Modrinth version ID. Modrinth mode resolves required dependencies and compatible project versions, checks client side, SHA-256, and pins every final artifact in provenance. No arbitrary scripts. |
| `download-installer` | Resolve an exact Forge/NeoForge artifact and store a SHA-256-verified installer in external cache. Requires pinned `--sha256`. |
| `launch-installer` | Execute real Forge/NeoForge Client Factory install plus isolated processors; accepts exact `--installer-file` and `--installer-sha256` to seed download cache. |
| `workspace` | Strictly validate and inspect a local workspace JSON recipe. |
| `apply-workspace` | Build real client from recipe and install its exact mods in unpublished staging, then publish once. Refuses existing destination. |
| `dedup-libraries` | Content-hash-based hardlinks for identical library JARs, no path/classpath deletion and no byte changes. |
| `lwjgl-download` | Validate `org.lwjgl` Maven coordinate, download/verify exact JAR and register unclassified LWJGL in active profile by default. Use `--register false` for native classifier files, which require target-specific registration later. |
| `patch-authlib` | Explicit class-only overlay of exact base authlib JAR; check expected SHA-256 for base JAR, patch JAR and output JAR. Unsafe/unknown paths refused. |

Each command validates the current plan **before** modifying anything and
performs mutations in a sibling staging directory. The immutable core runtime
identity (Minecraft version, loader, Java, resolution lock) remains unchanged;
custom output changes are explicitly reflected in the new InstallPlan digest.
Modified managed JARs are never called unchanged upstream JARs. A tampered
client or invalid action ledger blocks further updates until repaired.

## Commands

```sh
cd cli
# Install new Vanilla/Fabric/Quilt/Forge/NeoForge client
 go run ./cmd/neverlauncher runtime client-factory install-client \
   --minecraft 1.21.1 --loader fabric --loader-version 0.16.10 \
   --client-dir /srv/neverlauncher/clients/my-client

# Exact mods only. A local mods manifest is an array of entries such as:
# [{"path":"mods/example.jar","url":"https://.../example.jar","sha256":"<64hex>","side":"client"}]
# Offline: replace url with "file":"/trusted/artifacts/example.jar"
 go run ./cmd/neverlauncher runtime client-factory install-mods \
   --client-dir /srv/neverlauncher/clients/my-client --manifest mods.json

# Resolve a specific Modrinth version ID and all required compatible dependencies
 go run ./cmd/neverlauncher runtime client-factory install-mods \
   --client-dir /srv/neverlauncher/clients/my-client \
   --modrinth-version '<modrinth-version-id>'

# Store an exact installer in external immutable cache; --sha256 is mandatory
 go run ./cmd/neverlauncher runtime client-factory download-installer \
   --loader forge --minecraft 1.21.1 --loader-version 52.0.1 \
   --sha256 '<installer-sha256>' --cache-dir /srv/neverlauncher/installer-cache

# Forge/NeoForge materializer and real Java processors, with locally preverified JAR
 go run ./cmd/neverlauncher runtime client-factory launch-installer \
   --loader forge --minecraft 1.21.1 --loader-version 52.0.1 \
   --client-dir /srv/neverlauncher/clients/my-forge-client \
   --installer-file /srv/neverlauncher/installer-cache/forge/1.21.1-52.0.1/installer.jar \
   --installer-sha256 '<installer-sha256>' --processor-sandbox required

# Validate recipe before starting a build
 go run ./cmd/neverlauncher runtime client-factory workspace --file workspace.json
 go run ./cmd/neverlauncher runtime client-factory apply-workspace \
   --file workspace.json --client-dir /srv/neverlauncher/clients/from-workspace

# Eliminate duplicate physical library storage without removing classpath records
 go run ./cmd/neverlauncher runtime client-factory dedup-libraries \
   --client-dir /srv/neverlauncher/clients/my-client

# Download and activate one exact non-classifier LWJGL library
 go run ./cmd/neverlauncher runtime client-factory lwjgl-download \
   --client-dir /srv/neverlauncher/clients/my-client \
   --coordinate org.lwjgl:lwjgl:3.3.3 --sha256 '<verified-sha256>'

# Strict opt-in patching, no guessed version/hash/bridge substitution
 go run ./cmd/neverlauncher runtime client-factory patch-authlib \
   --client-dir /srv/neverlauncher/clients/my-client \
   --target libraries/com/mojang/authlib/4.0/authlib-4.0.jar \
   --patch /trusted/LauncherAuthlib-patch.jar \
   --base-sha256 '<original-sha256>' \
   --patch-sha256 '<patch-sha256>' \
   --expected-sha256 '<verified-result-sha256>'
```

**Modrinth mode:** `--modrinth-version` selects a specific immutable version ID. Required dependency versions provided only by project ID are resolved once against the pinned Minecraft version and loader, then frozen as exact version IDs in the action history. Optional dependencies are not installed automatically; unsupported client-side projects and missing/ambiguous files fail closed. `--modrinth-api` is reserved for controlled API mirrors and localhost fixture testing.

**Workspace format** (not executable remote scripts):

```json
{
  "schemaVersion": "neverlauncher.mirror-workspace.v1",
  "minecraft": "1.21.1",
  "loader": "fabric",
  "loaderVersion": "0.16.10",
  "mods": [
    {"path": "mods/example.jar", "file": "example.jar", "sha256": "<sha256-hex>", "side": "client"}
  ]
}
```

Relative workspace `file` paths resolve against the recipe directory.
Files from private sources, denied APIs or without verified checksums cannot
be installed silently. An offline pack can only be rebuilt on a fresh machine
if its user-supplied artifacts are available again; the generated plan stores
original URLs or manual SHA-256 provenance but does not embed an entire modpack.
Full CurseForge/Modrinth modpack import, permission UX and shared dependency resolver
are separate 0.27.5–0.27.7 work; sophisticated legacy authlib/classloader
bridges are scheduled for 0.27.8–0.27.9. Do not claim those as completed.

## Production safety / limitations

- **Security:** `--processor-sandbox process` isolates process lifetime and
  environment only. For untrusted installers on Linux, require the bubblewrap
  sandbox via `--processor-sandbox required` on a verified, isolated worker.
- **Hash + provenance:** every added JAR has an exact SHA-256, origin (URL or
  locally verified input), lockfile output digest and append-only action history.
  Restaging is transactional; interrupted downloads and faulty patches do not
  modify an existing verified client.
- **Compatibility:** non-classifier LWJGL registration modifies the selected
  profile but does not automatically remove old/conflicting libraries. OS/arch
  natives require target-aware rules. `patch-authlib` is a checked class-only
  overlay, not automatic version-dependent auth bridge generation.
- **No publication claim:** source builds and offline HTTP fixtures are tested;
  real Minecraft GUI launches, online-mode joins, Windows/macOS native runtime,
  external mod repositories, Java 8 legacy paths and strict Linux namespace
  execution have **not** been certified by this release package.
