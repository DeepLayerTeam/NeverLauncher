## Как понимать состояние

| Состояние | Значение |
| :--- | :--- |
| **Исходники готовы к проверкам** | Есть версия и исполняемые механизмы, но это ещё не свидетельство успешной приёмки |
| **Кандидат** | Предложена конкретная версия, требующая всех обязательных испытаний |
| **Заблокировано** | Хотя бы одно обязательное условие не доказано, неверно или не выполнено |
| **Сертифицировано** | Независимые действительные подтверждения привязаны к точному коммиту и окончательным пакетам |
| **Опубликовано** | Проверенная поставка появилась в официальном выпуске и её файлы соответствуют утверждённым байтам |

**Правило безопасности:** без доказательств ставьте **«не подтверждено»**, а не «пройдено». Процедура выпуска должна завершаться отказом, если не хватает обязательных данных.
