# 0.30.2 — Java SDK Core (real Java backend extension runtime)

**Baseline:** uploaded 0.30.1 source archive. **Release version:** 0.30.2. Implemented in `sdk/java/core/`, with a runnable and signable example under `examples/extensions/java-lifecycle/`.

## Implemented

1. Java 17+ SDK (`ExtensionManifest`, `Json`, `SemVer`, `DependencyResolver`, `Extension`, `ExtensionLifecycle`, `ExtensionContext`, `Cancellation`, `Deadline`). It parses the actual NeverExtensions manifest `2.0`, resolves dependencies locally with constraints, conflicts and cycles, and executes start/stop with deadline-enforced lifecycle states and cooperative cancellation.
2. `HostSession` and `ExtensionRunner` use **working authenticated loopback HTTP** against the existing Go Extension Host Protocol 1.0: real startup hello with PID/instance/extension/API validation and regular heartbeats. The JVM exits on host protocol failure rather than silently continuing outside supervision.
3. Real Java extension payload with `backend/bin` executable, SDK jar and implementation jar; assembled via a build script. Existing `nl extension pack` accepts the packaged extension and `nl extension verify` verifies its Ed25519 signature without changes to Go package format.
4. Runtime regression tests, a real child-process test (PID, hello, heartbeat, SIGTERM, stop callback), and six JDK/OS combinations in CI. Previous 0.30.1 module-parity audit continues working against its **frozen baseline** when the product version advances; existing evidence is not rewritten as if full module parity occurred.
5. All required project version metadata synchronised using `scripts/version/manage.py sync`.

## Important certification boundary

The SDK is executable Java code, not merely a contract. However, it is **not** the standalone Java Extension Host from 0.30.4, and it does not support event/command/config/secrets APIs from 0.30.3. No live production registry publisher key, real deployed NeverLauncher backend, cross-platform CI output or full Gravit M01–M19 integration has been certified in this local run. OS-level Java sandboxing is not claimed.

The POSIX sample uses a local JDK from `PATH`; production packages need a supported JDK 17+ installed in the extension runtime environment. Existing Go signing, permission and process supervision apply, and the trusted Minecraft JVM agent mode is distinct.
