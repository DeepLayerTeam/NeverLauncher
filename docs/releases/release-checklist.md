# Контрольный список выпуска 1.0.0

> **Рабочая ведомость для ответственного за релиз.** Непоставленная отметка означает «не подтверждено», а не «не требуется». Не заполняйте список по одному лишь наличию исходников или локальным контрактным тестам.

[Релизный центр](README.md) · [Описание версии](1.0.0.md) · [Нормативная приёмка](../acceptance/supported-platform-ga-1.0.0.md)

---

## А. Исходники и версия

- [ ] Версия в `VERSION` и компонентах согласована; указан точный 40-символьный коммит.
- [ ] Исходный коммит и данные выпуска неизменны на всех этапах.
- [ ] Пройдены контрактные и модульные проверки, требуемые для точной версии.
- [ ] История изменений и пользовательское описание не приписывают неподтверждённых возможностей.

## Б. Реальное испытание

- [ ] Независимо выполнены и подтверждены **все E2E-01–18**.
- [ ] Выполнена обязательная матрица реальных сочетаний Minecraft, Java, загрузчиков и игровых серверов.
- [ ] Проведены реальные установки и запуски Minecraft на всех шести целевых платформах.
- [ ] Проведены обязательные испытания длительного игрового процесса, нагрузки, восстановления и безопасности.
- [ ] Проверены сценарии авторизации, доступа владельца, обновления, отката и жизненного цикла опубликованного пакета.
- [ ] Все обязательные проверки CI завершились успешно для того же коммита.
- [ ] Нет открытых блокирующих дефектов P0/P1; независимый реестр закрытия дефектов проверен.

## В. Конечные нативные пакеты

- [ ] Windows x64: настоящий конечный `.exe`, нативная проверка подписи и запуска.
- [ ] Windows ARM64: настоящий конечный `.exe`, нативная проверка подписи и запуска.
- [ ] Linux x64: конечный `.deb` и отдельная подтверждённая `.asc`.
- [ ] Linux ARM64: конечный `.deb` и отдельная подтверждённая `.asc`.
- [ ] macOS x64: конечный `.pkg`, нативная проверка подписи и требуемая нотариализация.
- [ ] macOS ARM64: конечный `.pkg`, нативная проверка подписи и требуемая нотариализация.
- [ ] Размеры и SHA-256 **всех восьми файлов** совпадают с независимо закреплённым исходным индексом.

## Г. Независимое одобрение и состав выпуска

- [ ] Независимый GA-аудитор подготовил предусмотренные реальные свидетельства и подписанное одобрение.
- [ ] Действительность Ed25519-подписи и полномочия подписанта проверены с внешним якорем доверия.
- [ ] Коммит, версия, проект и контрольные суммы подтверждены без подстановок и тестовых фикстур.
- [ ] `publication_ga.py stage` завершился корректно, без перезаписи существующих пакетов.
- [ ] `publication_ga.py verify` подтвердил именно конечные байты.
- [ ] `RELEASE_MANIFEST.json`, `SHA256SUMS` и подпись охватывают все обязательные файлы.
- [ ] Исполнена заключительная проверка публикации; обязательные проверки не пропущены.

## Д. Публикация и последующий контроль

- [ ] Опубликована только прошедшая проверку поставка, а не произвольный архив исходников.
- [ ] Контрольные суммы публичных файлов совпадают с утверждённым набором.
- [ ] Пользовательские инструкции указывают ограничения подтверждённой поддержки.
- [ ] Сохранены закрытые доказательства, журналы и проверяемая ссылка на точный коммит.
- [ ] Назначен ответственный за реагирование на дефекты выпуска и готов сценарий отката.

## Решение

| Поле | Значение, которое заполняет оператор |
| :--- | :--- |
| Версия | `1.0.0` |
| Коммит | _Указать точный SHA_ |
| Сборки и проверки | _Приложить действительные ссылки и хеши_ |
| Независимое одобрение | _Указать проверенные свидетельства_ |
| Решение | **ЗАБЛОКИРОВАНО**, пока не подтверждены все обязательные условия |

Этот список — вспомогательная форма. Он **не выдаёт сертификат** и не изменяет автоматические требования `scripts/release/`. Для окончательного решения используйте [первичный регламент 1.0.0](../acceptance/supported-platform-ga-1.0.0.md) и [полную сквозную приёмку](../acceptance/full-real-user-ga.md).
