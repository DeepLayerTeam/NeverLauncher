# NeverLauncher 0.30.7 — Gravit Compatibility Adapter

## Shipped working behavior

- `sdk/java/gravit-compat`: Java 17+ independently implemented source-port adapter, preserving the fixed supported Gravit-style module lifecycle, metadata, `EventHandler` and `Command.invoke` signatures. It uses the existing NeverExtensions Host Protocol 1.0, no new REST endpoints.
- Real backend event subscriptions for `release.published` and `project.saved` (permission-checked and cancellable/timeout-bound at the existing host layer); raw payload and deduplication metadata preserved. **This does not implement Gravit's event cancellation semantics**.
- Commands are registered through the signed NeverExtensions CLI namespace and can run in backend RPC or a dedicated CLI JVM, with structured JSON replies when `CommandHandler.respond` is set. No root-level LaunchServer commands are registered.
- Go preflight refuses `Gravit` mode without declared source-port module class or adapter code in the JAR, and refuses Gravit module attributes on unrelated Java extensions. This validation is part of existing Java package inspection and manager install/update preflight.
- Self-contained signed `.nlext` example with a real JVM module using event -> durable storage -> CLI, plus standalone adapter SDK JAR for developing source ports.

## Security, limits and deployment

- Production Go signature verification, permissions, dependency resolution, lifecycle, rollback, heartbeat, RPC authentication and deadlines are inherited from 0.30.2–0.30.6; they are not reimplemented or bypassed.
- Java adapter code has **full access to its own JVM/process**; packaging and ACLs are trust controls, not an in-process sandbox. `pro.gravit.launchserver.*`, JavaFX, arbitrary old module JARs, and direct internal commands require a manual port and are not included.
- Upstream Gravit-specific phases, internal module dependencies and cancellable hooks are **not** claimed compatible. `Event.cancel()` and an unmapped event type reject at runtime. To use `LaunchServer` functionality, implement an explicit permission-checked NeverExtensions capability, not a fake `LaunchServer` object.
- Java compatibility tested with JDK 21 in this working environment; CI covers Java 17/21 on supported OS. Full deployed Go backend and OS CI results need independent execution before production certification.
