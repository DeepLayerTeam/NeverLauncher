# NeverLauncher 0.35.7 — Desktop accessibility and native UI

## Delivered code

- `desktop_accessibility_0357.ts` implements validated, local-only user UI preferences (Russian/English, 80–200% scaling, reduced motion, enhanced contrast), keyboard shortcuts, navigation policy and focus movement. Settings cannot modify signed project/manifest, native permissions or auth identity.
- Desktop React shell, navigation, signed onboarding, download/recovery and launch-settings views now use RU/EN strings for their primary controls and headings. The rest of the legacy screens still contain untranslated Russian copy; **English localization is partial**. User-facing content from project/backend/third-party extensions is not translated by the launcher.
- F6 moves focus between navigation and main content; navigation buttons support arrows/Home/End; Ctrl+1..9 or Cmd+1..9 opens a permitted screen; Ctrl/Cmd +/-/0 sets scaling. Existing first-run trust and permission restrictions are checked again for keyboard navigation, and shortcuts do not run inside editable fields or during IME composition.
- Skip-to-content link, semantic navigation, current-page marker, labelled progress, live readiness/error region, visible keyboard outlines, accessible checkbox controls and 40px+ primary targets. Reduced-motion and high-contrast preferences are enforced by CSS; system `prefers-reduced-motion` also works without a user setting.
- Native Tauri commands read actual OS/window display scale and perform real OS minimize/maximize/restore. Rust action dispatch is allowlisted to those two operations only; no arbitrary filesystem, shell or remote-access API has been added.
- Window layout adapts at narrow widths; UI zoom scales pixel-based legacy components as well. Separate native monitor scale information is refreshed on window resize and focus.
- Versions have been aligned to 0.35.7 in `VERSION`, Cargo, Tauri, Desktop and Admin npm metadata.

## Keyboard operation

| Windows/Linux | macOS | Result |
| --- | --- | --- |
| F6 | F6 | Focus nav / main section |
| Arrow keys, Home, End | same | Focus another navigation control |
| Ctrl + 1..9 | Cmd + 1..9 | Jump to one of the first nine permitted sections |
| Ctrl + +, -, 0 | Cmd + +, -, 0 | Increase, decrease, reset zoom |
| Tab, Shift+Tab | same | Default accessible focus order |

User preferences persist across Desktop updates in `neverlauncher.desktop.ui.0357` and are distinct from `neverlauncher.desktop.settings`. When no user choice exists, the verified owner's locale setting is the default. Signed configuration and OS security policies cannot be modified by these preferences.
