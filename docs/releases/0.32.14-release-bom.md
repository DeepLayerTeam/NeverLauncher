# NeverLauncher 0.32.14 — Release BOM (DEP08)

`RELEASE_BOM.json` is a **mandatory signed-release input**, not a template.
It is built from on-disk artifacts after Desktop/Admin/Backend/Guard/Runtime/
ServerBridge builds and certifications, and before creating `RELEASE_MANIFEST.json`,
`SHA256SUMS` and the Ed25519 release signature.

The BOM records the exact shared product version, SHA-256 and length of **every
pre-sign release file**, as well as hashes of the actual source dependency inputs
(`go.mod`, pinned `package-lock.json`, Rust component `Cargo.toml`, all Gradle
plugins, OpenAPI and certification targets). The independently-versioned extension SDK packages remain at their existing 0.21.0 versions and are pinned by source hash, not silently relabelled 0.32.14. Every release input must be present;
no optional fallback to `latest` is used. Platform artifacts that have been
imported from certification must already pass the existing cross-platform gates.

`neverlauncher release build` fails if required binaries, plugins, or source
metadata are absent or out of sync. `neverlauncher release sign` rechecks the
BOM before signing. `neverlauncher release verify` and `publish-check` rehash
all BOM artifacts, verify source component inventory, and apply the existing
Ed25519 trust-policy verification. Passing BOM validation *alone* does not
prove trust: the external release signing root must still be verified.

The BOM deliberately does not include `SHA256SUMS`, `RELEASE_MANIFEST.json`,
or signature envelopes in its own digests to avoid hash cycles. The existing
signed SHA256SUMS boundary covers `RELEASE_BOM.json`, `RELEASE_MANIFEST.json`
and all delivery files. Version 0.32.14 is the first version for which the new
BOM is mandatory; older signed bundles remain compatible with legacy checks.

## Verification

```sh
python3 scripts/version/manage.py check
cd cli && go test -race ./cmd/neverlauncher -run '^TestReleaseBOM03214'
# In a real signed build with independent signing/trust keys:
neverlauncher release verify /path/to/release-0.32.14 --public-key /trusted/release-public.key --trust-policy /trusted/policy.json
```

Do **not** combine independently downloaded `latest` binaries, runtime,
Guard or plugins into production. The BOM pins exact shipped content.
This work does not assert that six-platform certification, HA failover,
or a SQLite-only Backend has been completed.

**Release scope:** the BOM pins shipped artifact bytes; it does not assert
reproducible Rust dependency resolution without checked-in Cargo.lock files,
OCI image digest pinning, or cross-platform runtime compatibility certification.
Those remain separate gates before a public production announcement.
