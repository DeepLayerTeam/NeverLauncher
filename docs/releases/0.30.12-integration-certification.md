# NeverLauncher 0.30.12 — Integration & Certification

## Production changes

- Fixed a JVM-host failure-race in `extensionhost`: heartbeat, memory, startup and RPC probes cannot repeatedly terminate the same instance. The **original termination reason** survives the subsequent `Wait()` result, rather than becoming `signal: killed`. Status transitions expose `failing` before the process is reaped; crash-loop logic continues to use its existing bounded backoff/quarantine.
- Retained two real executable JVM processes for Java runtime + CLI regression; fixed Java SDK JAR naming drift (the SDK generated a `0.30.9` JAR while previous E2E packagers asked for `0.30.4`). Packagers now use the same stable built JAR; the versioned publication JAR derives its version from `VERSION`.
- Corrected Windows/MSYS Java classpaths in SDK/Gravit build scripts. All remaining Java 17-compatible sources still compile with `--release 17`.
- Updated the **current** 19-module evidence matrix to `compatibility/gravit/module-parity-03012.json`, while keeping the historic `03011` and `0301` inventories separately auditable. M17 retains the intentionally blocked unsafe functionality, and no `verified`/complete parity status is inferred from source presence or E2E alone.
- Added `scripts/certification/run_integration_03012.py`, an **executable allowlisted subprocess test runner**, not a manifest-only certification. It runs real JVM/JAR/CLI/Go/Node/Python suites, separately records process exit code, timeout, detected skipped tests, command, and output digest, and writes evidence even when a test fails. It does **not** save raw secrets or test output.
- Added fail-closed cross-platform review `scripts/certification/review_integration_03012.py`: Linux, macOS, and Windows each require an exact platform-specific test set and identical 40-character Git revision. Missing, skipped, failed, duplicated, or forged full-parity evidence is rejected. A passing review certifies these particular automated gates, **not** functional identity with every Gravit module or live Minecraft login.
- Added multi-platform CI running real Java extension-host E2E, Gravit-ported JVM modules, trusted JVM agent, DevTools CLI/auth, Discord IPC, LAN pin tests, source-map uploader, desktop asset prebuild, parity audit, Java lifecycle/runtime, and Linux Go-supervised JVM hang tests. Native desktop Vite/Tauri compilation is an additional mandatory CI job.

## How to run

```sh
python3 scripts/certification/test_integration_03012.py
python3 scripts/version/manage.py check
python3 scripts/certification/run_integration_03012.py \
  --cases java-sdk,jvm-host-e2e,gravit-e2e,java-lifecycle-e2e,java-runtime-e2e,trusted-agent-e2e,devtools-e2e,lan-security,discord-ipc,devtools-security,sentry-backend,asset-integrity,sentry-release,module-parity \
  --cli /absolute/path/to/private/build/nl \
  --report /absolute/path/to/evidence.json --timeout 300
```

The **additional** `java-supervisor-go` case requires Go dependencies and `NEVERLAUNCHER_TEST_JAVA_HOST_JAR`, which the runner sets when building the real JVM host example. This case must run on Linux CI with working dependency download/cache:

```sh
python3 scripts/certification/run_integration_03012.py \
  --cases java-supervisor-go --report /absolute/path/to/supervisor.json --timeout 300
```

The GitHub Actions workflow `.github/workflows/integration-certification-03012.yml` is the release gate. Local reports with `revision=unknown` cannot pass its cross-platform verifier.

## Actual local verification and limits

- Verified independently on Linux with JDK 21: Java SDK Core/Runtime tests, JVM-host hello/ready/authenticated RPC/timeout, Gravit module callbacks/commands, lifecycle SIGTERM, and Java backend-event-storage-CLI subprocess workflow.
- Verified `nl` CLI compilation, M02/M04/M13/M14/M15/M17/M18/M19 parity regression, signed trusted JVM fixture, DevTools JAR/auth fixture E2E, Go LAN/Discord/DevTools race tests, Go Sentry reporter, Node asset index/prewarmer, and Python release upload tests.
- Go `services/api/internal/extensionhost` test execution could **not** be confirmed locally: offline Go module cache is missing `github.com/jackc/pgx/v5`. The existing Go supervisor JVM fixture and new concurrent-failure regression tests are included in CI but must be run there before certification.
- The combined 14-case local runner was interrupted by an external execution limit after the lifecycle case; Java runtime passed when rerun separately. No complete 14-case combined report is claimed.
- Windows/macOS CI, native Tauri, actual Discord Desktop client, real Minecraft (vanilla/Forge/Fabric) runtime, live Sentry Cloud and production authentication systems were **not** executed locally. Full M01–M19 Gravit module parity remains **unverified**.

Security: Trusted in-process JVM agents retain full access to their JVM; they are not sandboxed. DevTools `process` isolation is not an OS sandbox. mDNS advertisements cannot establish TLS trust; certificate fingerprints must come from an independently trusted source.
