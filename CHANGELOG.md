# История изменений NeverLauncher

## 1.0.0 — Supported Platform GA (код кандидата; публикация зависит от независимой приёмки)

- Основные продуктовые пакеты Admin, Desktop, CLI, Runtime/Guard и конфигурации совместимости синхронизированы с `VERSION=1.0.0`.
- Подписание промышленного выпуска теперь требует независимо подписанных реальных E2E-01–18 и точных исходных байтов шести нативных установщиков (Windows x64/ARM64, Linux x64/ARM64, macOS x64/ARM64) и двух отдельных Linux-подписей. Отсутствующие данные блокируют выпуск.
- Исполняемый этап `publication_ga.py stage` проверяет независимое Ed25519-одобрение, закреплённый SHA-256 индекса и каждый пакет, а затем переносит настоящие файлы в подписываемый выпуск. При ошибке копирования частичный перенос откатывается; перезапись пакетов запрещена.
- Go-компонент сборки и проверки релиза независимо проверяет SHA-256 и размеры этих восьми файлов и включает их в обязательные файлы `RELEASE_MANIFEST.json`, которые защищены `SHA256SUMS` и подписью выпуска.
- Перед сетевой публикацией Python повторно проверяет подписи, конечные байты, обязательный публичный отчёт `SUPPORTED_PLATFORM_GA_1000.json`, CI и подписанный выпуск. Новые версии не могут обойти эту проверку простым изменением номера версии.
- Защищённые GitHub Actions теперь принимают отдельно заверенные свидетельства GA 1.0.0, соответствующие точному source SHA; источники свидетельств и ключи не копируются в публичный пакет.

**Статус:** изменения — рабочий код релизного шлюза, а не выданный сертификат выпуска. Пока физическая независимая приёмка E2E-01–18, подписанные нативные пакеты и все обязательные GitHub CI jobs не завершены для одного и того же коммита, публичный GA-выпуск заблокирован. См. [Supported Platform GA 1.0.0](docs/acceptance/supported-platform-ga-1.0.0.md).
