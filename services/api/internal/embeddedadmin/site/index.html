Content & Profile Migration (MIG07)

Сопоставляет реальный ClientProfile и проверенные файлы ZIP с новым Build Workspace. Не импортирует ключи, auth или неизвестные модули. Импорт можно повторять после прерывания.













Module & ServerWrapper Migration (MIG08)

Проверка JAR без исполнения, проверка исходного ZIP по MIG03, отчёт по неизвестным модулям. Перенос старых ServerWrapper токенов запрещён.













Isolated Migration Rehearsal (MIG10)

Запуск только из CLI в отдельном тестовом окружении; Backend выполняет независимую проверку UUID и сохранённых MIG03–MIG08. Не является разрешением на production cutover.




Staged Cutover (MIG11)

Рабочее переключение `channel_heads`. Staging блокирует публикацию указанного профиля/канала в PostgreSQL. Остановка Gravit/world/SQL writers выполняется оператором отдельно; подтверждение и SHA не доказывают её автоматически.









Для activation введите ожидаемую ревизию cutover receipt (не channel head), ссылку на внешнее доказательство fencing и SHA-256 независимо полученного snapshot текущего Gravit.










Сначала выполните dry-run. Импорт не обновляет пароли существующих пользователей, не переносит токены или права и не разрешает cutover.


Экспорт содержит исходные конфигурации и может включать пароли/ключи. Сохраняйте его в защищённом каталоге.
