# Публичный Доверие к устройству Матрица

`device-trust/targets.json` — policy-файл NeverLauncher Доверие к устройству CI. Он описывает обязательные цели и проверяет, но **не** хранит PASS/FAIL. Результат создаётся только из CI свидетельство для точный продукт версия, Git фиксация и GitHub Действия запуск ID.

## Цели 0.13.0

## Доверие к устройству Сертификация релиза 0.13.0

Каждый обязательный цель дополнительно обязан пройти `deviceTrustRelease0130`. Протокол цель проверяет среда выполнения `/api/v1/auth/capabilities`, `/ready` и запечатанный схема базовая линия `0018`; нативный цели запускают отдельный отказ с блокировкой ключ жизненный цикл тест. Агрегат `matrix.json` используется как вход официальной сертификация релиза: `nl release build --device-trust-matrix... --device-trust-targets... --source-commit...` создаёт `DEVICE_TRUST_CERTIFICATION.json`, а `nl release publish-check` для 0.13.0 отклоняет комплект без неё.


- `postgres-protocol-linux-x64` — рабочий PostgreSQL Доверие к устройству протокол E2E.
- `native-linux` — Tauri/device-key compile + ключ-политика модульные тесты на Linux исполнитель.
- `native-windows` — тот же нативный граница на Windows исполнитель.
- `native-macos` — тот же нативный граница на macOS исполнитель.

Протокол E2E проверяет registration/replay защита, сессия привязка эпоха, привязанный к устройству обновление, dual-доказательство ротация, постоянный отпечаток метка удаления, ServerBridge привязка инвалидация, отзыв каскад, риск step-up, P-256 запрос-ответ аттестация протокол, обязательный устойчивый к фишингу восстановление prerequisite и успешный восстановление после подписанной WebAuthn P-256 утверждение процедура.

Нативный цели проверяют compilation и безопасность-политика тесты существующего ключ жизненный цикл: OS-область ключ пространство имён, оборудование серверная часть отказ с блокировкой classification, генерация-область оборудование метки, канонический ключ замена полезная нагрузка, обновление привязка полезная нагрузка и аттестация полезная нагрузка.

## Свидетельство граница

Каждый цель создаёт `device-trust-result.json`. `scripts/device_trust/matrix.py` отказ с блокировкой проверяет цель идентичность, версия, точный commit/run ID, обязательные проверяет, безопасные имена evidence-файлов, их фактическое наличие и SHA-256 каждого файла. Подмена или удаление лога/JSON свидетельство после выполнения цель делает матрица ошибка. Для протокол цель дополнительно обязательно `repository=postgresql`, `privateKeyServerExposed=false` и `vendorHardwareProvenance=not-verified`.

P-256 запрос-ответ в CI подтверждает корректность NeverLauncher протокол и владение зарегистрированным тест ключ. Он не является TPM кавычки, Защищённый Анклав сертификат или другим поставщик удалённый-аттестация доказательство. Нативный исполнитель также не считается доказательством фактической работы защищённого хранилища/HSM на конкретном пользовательском компьютере.


### Миграция стабилизация свидетельство 0.12.10

Протокол цель дополнительно требует `migrationStabilization01210`. Перед основным жизненный цикл E2E процесс воспроизводит точный `0.12.9` PostgreSQL схема (`0001..0017`) и запускает `e2e/scripts/run-device-trust-migration-e2e.sh`. Его `migration-stabilization.json` входит в хеш-проверен публичный свидетельство, поэтому агрегатор не принимает PASS, если обновление `0.12.9 → 0.12.10` не выполнен или его свидетельство отсутствует/изменён.

Проверяется не только применение `0018`, но и исправление `key-rotate`/`key-recover` назначение ограничение, NULL-normalization необязательный устройство ссылки и DB-уровень запрещать для межпользовательский session/device, замена и Minecraft доверие связывает.

## Локальная проверка policy/aggregator

```bash
python3 scripts/device_trust/matrix.py validate --targets device-trust/targets.json
python3 scripts/device_trust/test_matrix.py
```

Рабочий протокол E2E требует Docker и PostgreSQL клиент. Сначала выполняется точный-обновление E2E, затем жизненный цикл E2E:

```bash
bash e2e/scripts/run-device-trust-migration-e2e.sh
bash e2e/scripts/run-device-trust-e2e.sh
```

Публичный процесс: `.github/workflows/device-trust.yml`. Агрегированные `matrix.json` и `matrix.md` публикуются в GitHub Действия Summary/artifact только из результатов текущего запуска.
