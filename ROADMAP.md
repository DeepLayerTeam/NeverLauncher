# Дорожная карта NeverLauncher

План после текущего состояния исходников `0.21.5`. Это направления работы, **не обещание сроков, версий и завершённой реализации**. Приоритеты меняются по результатам тестов и feedback.

| Приоритет | Направление | Критерий готовности |
| --- | --- | --- |
| P0 | CI и релизные контракты | Все обязательные jobs проходят на одном exact SHA; сертификаты собраны и проверены |
| P0 | Windows/NeverGuard adversarial testing | Негативные тесты корректно отклоняют неподходящие случаи, подтверждён platform evidence |
| P1 | Production security | Секреты, подписи, TLS, RBAC, восстановление и расширения проходят аудит и негативные тесты |
| P1 | Реальная Minecraft-совместимость | Опубликованные значения `required` подтверждены реальными клиентскими прогонами, остальные ясно помечены NOT CERTIFIED |
| P2 | Полный путь администратора | Проекты/каналы/серверы/пакеты управляются через UI без обязательного ручного API |
| P2 | Клиентские функции | UI optional mods, текстуры, диагностика и проверка запуска проходят end-to-end |
| P2 | Официальная Minecraft-аутентификация | Фактическая цепочка сервисов/ownership подтверждена интеграционными тестами, без подмены Microsoft OIDC |
| P3 | SDK и NeverExtensions | Стабильные интерфейсы, примеры, sandbox boundaries, lifecycle и compatibility gates |
| P3 | Документация и сопровождение | Руководства соответствуют поведению, есть ownership и воспроизводимые инструкции |

## Порядок выпуска

Исправление → unit/contract tests → integration/e2e → платформенная матрица → точный commit SHA → `scripts/release/preflight.sh` → подписанная поставка. Ни один пройденный smoke-тест сам по себе не разрешает production release.

Открытые задачи отслеживайте через [GitHub Issues](https://github.com/DeepLayerTeam/NeverLauncher/issues); возможности реального клиента описаны в [COMPATIBILITY.md](COMPATIBILITY.md).
