# Поддержка NeverLauncher

> Чтобы проблему можно было воспроизвести, указывайте точный коммит или версию, окружение и фактический результат. Перед отправкой удаляйте секреты и персональные данные.

## Куда обращаться

| Тема | Канал |
| :--- | :--- |
| Ошибка, регрессия, неожиданное поведение | [Задачи GitHub](https://github.com/DeepLayerTeam/NeverLauncher/issues) |
| Предложение или обсуждение возможностей | [Обсуждения GitHub](https://github.com/DeepLayerTeam/NeverLauncher/discussions), если доступны |
| Недочёт документации | Задача по шаблону ошибки документации |
| Уязвимость | [Закрытый порядок сообщения](SECURITY.md), **не** открытая задача |

## Что приложить к обращению

- Версию из [`VERSION`](VERSION) и, по возможности, точный коммит.
- ОС, архитектуру, компонент, используемую версию Minecraft и загрузчик — если проблема относится к игре.
- Краткие шаги воспроизведения, ожидаемый и фактический результаты.
- Очищенные от секретов журналы, идентификаторы связанных проверок CI, контрольные суммы — если это необходимо для диагностики.

Начните с [типовых проблем](docs/troubleshooting/common.md), [матрицы совместимости](COMPATIBILITY.md) и [быстрого старта](docs/getting-started/quickstart.md). Для вопросов о статусе выпусков существует [релизный центр](docs/releases/README.md).

Поддержка через задачи и обсуждения предоставляется по мере возможности; гарантированных сроков ответа или обязательств по уровню обслуживания этот документ не устанавливает.
