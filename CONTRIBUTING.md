# Участие в разработке

Спасибо за интерес к NeverLauncher. Пожалуйста, проверяйте существующие [issues](https://github.com/DeepLayerTeam/NeverLauncher/issues) и обсуждения перед созданием дублирующих предложений.

## Сообщение о проблеме

Для обычных ошибок используйте шаблон **Bug report**; приложите версию из `VERSION`, ОС/архитектуру, компонент, шаги воспроизведения, фактический и ожидаемый результат, сокращённые логи **без токенов/секретов**. Для уязвимостей — только [процедура SECURITY.md](SECURITY.md), не публичный issue.

## Pull request

1. Создайте ветку от актуального `main` и опишите одну логическую цель.
2. Добавьте тесты на исправленный сценарий, включая негативные проверки и совместимость при необходимости.
3. Убедитесь, что `python3 scripts/version/manage.py check` и `python3 scripts/contracts/validate-openapi.py` не сломаны.
4. Выполните релевантные проверки из [DEVELOPMENT.md](DEVELOPMENT.md).
5. Для API обновите OpenAPI; для возможностей пользователя — `docs/` и README; для миграций укажите план обновления/отката.
6. Заполните `.github/PULL_REQUEST_TEMPLATE.md` и проверьте, что в diff нет `.env`, приватных ключей, токенов и бинарных артефактов.

Вклад в программу может быть принят, доработан или отклонён сопровождающими; соблюдайте [кодекс поведения](CODE_OF_CONDUCT.md). По вопросам авторства и прав смотрите [LICENSE](LICENSE) и [NOTICE](NOTICE). Отправляя PR, вы соглашаетесь предоставить свой вклад на условиях лицензии репозитория при наличии соответствующих прав.
