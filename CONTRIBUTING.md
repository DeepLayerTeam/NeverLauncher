# Участие в разработке

NeverLauncher — русскоязычный открытый-исходник проект. Все пользовательские материалы, описания задач, merge запрос, сообщения интерфейса и документация должны быть на русском языке.

## Перед началом работы

1. Ознакомьтесь с README.
2. Проверьте актуальную документацию проекта.
3. Найдите существующую задачу или создайте новую.
4. Обсудите крупные архитектурные изменения до реализации.

## Требования к merge запрос

- Изменение должно быть связано с выдача/задачей проекта.
- Описание merge запрос пишется на русском языке.
- Для пользовательских изменений нужно обновить README, схемы, примеры или Wiki-страницу.
- Новые настройки должны иметь безопасные значения по умолчанию.
- Изменения в манифестах должны проходить валидацию JSON Схема.

## Стиль проекта

- Пользовательские тексты — на русском языке.
- Технические идентификаторы — по необходимости на английском.
- Ошибки CLI должны быть понятными и пригодными для диагностики.
- Серверная часть должен возвращать структурированные ошибки.
- Конфигурации должны быть явными, без скрытой магии.

## Компоненты

- `services/api` — серверная часть API на Go.
- `cli` — CLI на Go.
- `apps/desktop` — настольное приложение клиент.
- `apps/admin` — администратор panel.
- `schemas` — машинно-читаемые спецификации.
- `deploy` — инфраструктурные примеры.
- `examples` — примеры конфигурации.

## Версия проекта

`VERSION` в корне репозитория — единственный редактируемый источник версии NeverLauncher.
Не меняйте вручную версии в `package.json`, `Cargo.toml`, Tauri метаданные или рабочий env-шаблонах.

Обновление версии выполняется одной командой:

```bash
python3 scripts/version/manage.py set <version>
```

Если `VERSION` уже изменён вручную, синхронизируйте обязательные метаданные:

```bash
python3 scripts/version/manage.py sync
```

Проверка без изменения файлов:

```bash
python3 scripts/version/manage.py check
```

Go бинарные файлы получают версию через `-ldflags`, Admin/Desktop — из `VERSION` во время Vite сборка, ServerBridge — через Gradle-сгенерированный `BridgeVersion`, а совместимость/E2E инструментарий читает `VERSION` напрямую.
