# Кодекс поведения

NeverLauncher развивается как профессиональный open-source проект для разработчиков Minecraft-серверов и игровых проектов.

## Ожидаемое поведение

- уважительное общение;
- техническая аргументация вместо личных нападок;
- конструктивная критика;
- ясные issue и merge request;
- уважение к времени сопровождающих проекта.

## Недопустимое поведение

- оскорбления и травля;
- публикация вредоносного кода;
- намеренное усложнение обсуждений;
- раскрытие приватной информации;
- спам;
- провокации, не связанные с развитием проекта.

## Принцип проекта

NeverLauncher должен оставаться инженерным проектом с ясной архитектурой, безопасными практиками и понятной коммуникацией.
